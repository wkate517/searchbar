# searchBAR

SearchBAR is a student-centered website that helps college students discover nearby bars and nightlife spots. 

## Project Summary

The original front end for searchBAR was created using React and Vite. The project uses JSX to organize the website’s structure and CSS to control the layout, colors, fonts, buttons, search bar, navigation options, and bar information cards. React state is used to make parts of the website interactive, such as the search and explore options. The current version is a front-end draft, while database features and additional functionality will be added later.

## Live Website

[View the SearchBAR draft](https://searchbarsd.netlify.app/)

## Features

- Search for bars and nightlife locations
- Explore locations by vibe and music
- View bar details, ratings, and reviews
- See the best nights to visit
- Add or suggest new locations
